# MetCam
MetCam: Sistema de visualización meteorológica con una plataforma de monitoreo atmosférico en tiempo real, que integra datos del modelo GFS (0.25°) de Chile Continental, Insular y la Antártica. MetCam procesa dinámicas de viento y presión a través de modelos numéricos (NWP) para ofrecer una visión técnica y precisa de la meteorología del H.S.
